# Copilot CLI Custom Windows Notification System

This directory is a self-contained GitHub Pages site generated from the Markdown documentation.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `copilot-cli-notification-docs`.
2. Upload `index.html` to the repository root and commit it to `main`.
3. Open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)` and save.
6. After deployment, the site will be available at:

   `https://YOUR-GITHUB-HANDLE.github.io/copilot-cli-notification-docs/`

The site is a single self-contained HTML file. It has no external CSS or JavaScript dependencies.

## Interactive features

- Table of contents with active-section highlighting
- Search across the documentation
- Copy buttons on code blocks
- Light/dark theme toggle
- Responsive layout for desktop and mobile
